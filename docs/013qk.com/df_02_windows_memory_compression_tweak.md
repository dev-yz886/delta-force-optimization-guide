# 《三角洲行动》大战场后期内存假死排查：禁用 Windows 内存压缩与工作集锁定

> **发布站点**：https://013qk.com/df/df_02_windows_memory_compression_tweak.html  
> **核心领域**：Windows 10/11 游戏模式、后台进程资源争抢、内存压缩与全屏优化

## 核心排查结论

**核心排查结论：**16GB 物理内存玩家在三角洲行动大战场模式交战进行到第 20 分钟时频繁出现持续数十秒的画面假死，罪魁祸首是 Windows 系统进程（System）内置的“内存压缩（Memory Compression）”机制在可用 RAM 低于阈值时强占 CPU 单核算力对页面进行实时压缩与解压，通过以管理员身份在 PowerShell 中执行 `Disable-MMAgent -mc` 彻底关闭内存压缩可彻底杜绝假死。

## 二、 核心排查与系统调优步骤

### 步骤 1：PowerShell 查看当前系统内存管理配置

以管理员身份启动 PowerShell，执行诊断命令：

```powershell
Get-MMAgent

# 观察输出结果中的 MemoryCompression 是否为 True。
```

### 步骤 2：以管理员权限彻底关闭内存压缩机制

执行以下指令切断内存压缩：

```powershell
Disable-MMAgent -mc

# 执行完成后重启计算机，再次运行 Get-MMAgent 确认 MemoryCompression 变为 False。
```

### 步骤 3：在本地安全策略中赋予用户“锁定内存页”权限

按 Win+R 输入 <code>secpol.msc</code> 打开本地安全策略：
1. 展开【本地策略】->【用户权限分配】；
2. 在右侧找到【锁定内存页（Lock pages in memory）】；
3. 双击打开，点击【添加用户或组】，输入当前登录用户名并保存，防止游戏关键工作集被强制置换出物理内存。

## 三、 常见误区与 FAQ

#### Q: 内存压缩的设计初衷是什么？为什么玩游戏反而更卡？

A: 微软设计内存压缩是为了让只有 4GB/8GB 内存的低端轻薄本在开很多网页时不报内存溢出。但压缩和解压需要耗费高频 CPU 算力，对每一毫秒都必须极速响应的三角洲来说，这种后台解压就是致命的卡死瓶颈。

#### Q: 32GB 内存玩家需要关闭内存压缩吗？

A: 32GB 内存虽然不一定会触发极限压缩，但关闭后系统进程的 CPU 占用更为纯净，杜绝偶发性工作集重构，建议同样关闭。

#### Q: 关掉之后如果内存真的用完了会怎样？

A: 关掉内存压缩后，物理内存吃满时系统会直接使用高速 NVMe 固态硬盘上的 Pagefile 分页文件（配合此前设置的 24GB 固定页面文件），其响应时间远比单核 CPU 苦苦解压快得多。
